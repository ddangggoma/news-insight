# 중복 묶음 · 교차 신호 · 분류 런북 (Phase 4)

매일 들어오는 수만 건의 항목을 같은 기사·같은 사건끼리 묶고, 논문·오픈소스·커뮤니티·미디어를 잇고, DX 관점으로 분류하는 과정입니다.

## 1. 흐름

```
수집 → 한국어 카드 + 분류 (launchd 10분, Antigravity → Qwen)
          │  분야·테마·DX 사업부·영향·범위·관련도
          ▼
stories.cluster (Celery 5분) — 카드가 생긴 항목만
   1) 정확 중복: 같은 URL(AMP·모바일 통합) 또는 같은 본문 해시
   2) 근접 중복: 한국어 제목 MinHash 유사도 ≥ 0.45 (LSH 후보)
   3) 같은 사건: 카드 키워드 공유 + 유사도 ≥ 0.35 + 날짜 차이 2일 이내
   4) 해당 없으면 새 이슈
   + arXiv ID·DOI·GitHub 저장소 추출 → 교차 신호
          ▼
콘솔: 카드 뉴스(분류 필터·이슈별 1건) · 이슈 묶음 · 교차 신호 · 관련성 검토(AI 일치율)
다이제스트: 무관·제외 항목 제거, 이슈 대표 기사만, 보도 매체 수 반영
```

## 2. 분류 기준

| 축 | 값 |
|---|---|
| 분야(15)·테마(75) | `apps/api/src/news_insight/taxonomy/catalog.py` (웹 라벨은 `apps/web/lib/taxonomy.ts`, 테스트로 일치 검사) |
| DX 사업부 | MX(모바일·온디바이스 AI) · VD(디스플레이·영상) · DA(생활가전·홈로봇) · Networks(5G Adv·6G) · Health(디지털 헬스·의료기기) · Harman(전장·SDV) |
| 영향 | 기회 · 위험 · 관찰 |
| 범위 | `dx`(DX 제품·기술) · `dx_dependency`(완제품 성능·원가에 직결되는 의존 기술) · `excluded`(메모리·파운드리 증설 같은 반도체 자산 투자) · `irrelevant`(무관) |
| 관련도 | 0~100 (DX 기술 전략 담당자에게 유용한 정도) |

- 분류 기준을 바꾸면 `TAXONOMY_REVISION`을 올립니다. 이전 기준으로 분류된 카드는 다시 만들어집니다(새 항목 우선).
- 카드 뉴스의 범위 필터 "DX 관련만"은 `dx`와 `dx_dependency`를 뜻합니다.

## 3. 점검 명령

```bash
cd apps/api
uv run --env-file ../../.env news-insight stories run                 # 즉시 묶기 (기본 5,000건)
uv run --env-file ../../.env news-insight stories eval --size 200     # 임계값 평가 (Antigravity 판정, 약 4회 호출)
```

`stories eval`은 실제 후보 쌍(항목과 가장 비슷한 최근 항목)을 뽑아 Antigravity에게 "같은 사건인가"를 판정하게 하고, 임계값별 정밀도·재현율·F1을 보여 줍니다. F1이 가장 높은 값을 `stories run --near/--event`나 `Thresholds` 기본값에 반영합니다.

## 4. 관련성 평가

콘솔 → 관련성 검토의 "AI 분류 일치율"은 사람의 판정(관련/무관, 애매 제외)과 AI 범위 판정(`dx`·`dx_dependency` = 관련)을 비교한 값입니다.
- 정밀도: AI가 관련이라고 한 것 중 실제 관련 비율
- 재현율: 실제 관련 중 AI가 관련이라고 한 비율

무관 판정이 많은 소스는 "무관 판정이 많은 소스" 표에서 확인해 비활성화를 검토합니다.
