## 0. 분류 체계 변경 (2026-10-04)

위자드로 고른 R2 분류(분야 23·제품군 18)는 `main`에 먼저 합쳐진 P4 분류와 같은 카드 호출을 두고 겹쳐서 **되돌렸다**. R4는 P4 체계를 쓴다.

| 축 | 값 | 카드 컬럼 (`item_cards`) |
|---|---|---|
| 분야 15 | `taxonomy/catalog.py` FIELDS (AI·데이터, 반도체, 모바일·엣지, 디스플레이·미디어, 네트워크·통신 …) | `field` (1개) |
| 테마 75 | 분야별 5개 | `themes` (여러 개) |
| DX 사업부 6 | MX, VD, DA, Networks, Health, Harman | `businesses` (여러 개) |
| 영향 3 | 기회·위험·관찰 | `impact` |
| 범위 4 | `dx`·`dx_dependency`·`excluded`·`irrelevant` | `scope` |
| 관련도 | 0~100 | `relevance` |

웹 라벨은 `apps/web/lib/taxonomy.ts`를 재사용한다. 위자드의 제품군 축은 P4 체계에 축을 더하는 별도 작업으로 미룬다.

## 1. 목표와 범위

로그인 없이 누구나 여는 독자용 웹. **찾기**는 시안 B(패싯 탐색), **흐름 보기**는 시안 C(분야 × 사업부 레이더).

| 포함 | 제외 |
|---|---|
| 홈 = 탐색(B), 기사 상세, 레이더(C), 공개 다이제스트·아카이브·RSS | 일 롤업·z-score (R3), 기간 리포트 서술 (R5), `/console` 이전 (R6) |
| 공개 조회 API `/api/public/*` (집계는 실시간 쿼리) | 북마크·읽음 표시, 키워드 페이지 |
| 반응형, 라이트·다크, Playwright E2E | 콘솔 화면 변경 (다른 세션 작업 영역) |

**다른 세션과 겹치지 않게:** 새 코드는 `apps/api/src/news_insight/public/`, `apps/web/app/(reader)/`, `apps/web/components/reader/`에만 둔다. 기존 파일은 꼭 필요한 곳만 최소로 고친다(`main.py` 라우터 등록, `app/page.tsx` 삭제, `lib/query.ts` 배열 지원, Caddy 차단 한 줄, `.env.example` 키 한 줄). 콘솔·카드·묶음 코드는 읽기만 한다.

**R3과의 관계:** 집계는 `items` + `item_cards` + `story_items`를 그때그때 GROUP BY 한다. 응답 형태를 고정해 두고 R3에서 내부만 롤업 조회로 바꾼다. 그 전까지 "급상승"은 **직전 같은 길이 기간 대비 증감률**로 계산하고 그렇게 표기한다.

## 3. 화면

### 3.1 탐색 홈

| 영역 | 내용 |
|---|---|
| 패싯 (좌 240px) | 범위(DX 관련만 / 의존 기술 포함 / 전체), 분야 15(선택하면 그 분야 테마 5개가 펼쳐짐), DX 사업부 6, 영향 3, 트랙 4, 지역 5. 각 값 옆 건수, 0건은 흐리게 |
| 피드 | 필터 칩, 건수(기사 N · 이슈 M), 정렬(최신·관련도·보도 매체 수), **이슈별 1행**(묶음 대표 기사, "관련 기사 N건 · 매체 M곳"), 30개씩 더 보기 |
| 인사이트 (우 300px) | 많이 언급된 키워드 6(직전 기간 대비 증감), 분야 점유율, 사업부 분포, 영향 분포, 함께 언급된 키워드 |

기사 행: 분야·사업부 태그 → 한국어 제목 → 요약 2줄(`text-ink-2`) → 영향·관련도·반응 지표·묶음 크기·키워드.

### 3.2 기사 상세

분류(분야·테마·사업부·영향·범위·관련도), 한국어 제목, 원제, 출처·지역·시각, 요약, 키워드, 원문 링크, **같은 이슈의 다른 보도**(story_items), **교차 신호**(item_refs로 이어진 논문·저장소·커뮤니티 글). 본문 전문은 보여 주지 않는다.

### 3.3 레이더

| 영역 | 내용 |
|---|---|
| KPI 4 | 분석 기사(직전 기간 대비), 새 이슈 수, 가장 빠르게 뜨는 칸(최소 건수 이상 중 증가율 1위), 교차 신호 이슈 수(트랙 2개 이상 섞인 묶음) |
| 히트맵 | **분야 15(행) × 사업부 6(열)** + "사업부 미지정" 열. 칸 = 건수 + 직전 대비 ▲▼%. "표로 보기" 전환 |
| 칸 상세 | 건수·증감, 최근 8개 기간 추세, 테마 분포, 많이 언급된 키워드, 대표 이슈 4, "이 조합으로 탐색" 링크 |
| 분야 모멘텀 | 분야별 건수·증감·8기간 스파크라인·점유율·상태 |
| 관심 대비 실체 | 분야별 산점도: 가로 = 뉴스+커뮤니티 증감률, 세로 = 논문+오픈소스 증감률 |
| 키워드 변화 | 새로 등장·증가·유지·감소 4열 (직전 4개 기간 건수로 임시 판정, R3에서 교체) |

## 5. 공개 조회 API (`apps/api/src/news_insight/public/`)

| 경로 | 파라미터 | 응답 |
|---|---|---|
| `GET /api/public/taxonomy` | — | 리비전, 분야(테마 포함)·사업부·영향·범위 라벨 |
| `GET /api/public/items` | `period`(1d·7d·30d·all), `scope`(relevant·dependency·all), `field[]`, `theme[]`, `business[]`, `impact[]`, `track[]`, `region[]`, `q`, `sort`(recent·relevance·coverage), `page`, `size≤50` | `Page[ReaderStory]` (이슈별 1건) |
| `GET /api/public/items/{id}` | — | `ReaderItemDetail` (+ 같은 이슈 보도, 교차 신호) |
| `GET /api/public/facets` | items와 같은 필터 | 축별 `{key, count}`. 각 축은 **그 축의 선택을 뺀** 필터로 계산 |
| `GET /api/public/insights` | items와 같은 필터 | 키워드 상위(이번·직전 건수), 분야 점유율, 사업부 분포, 영향 분포, 동시출현 키워드 |
| `GET /api/public/radar` | `period`(day·week·month·quarter), `key`, `scope` | KPI, 히트맵, 분야 모멘텀(8기간), 산점도, 키워드 변화 |
| `GET /api/public/radar/cell` | `period`, `key`, `field`, `business`, `scope` | 칸 상세 |
| `GET /api/public/digests`, `/latest`, `/{date}` | `page` | 기존 다이제스트 스키마 |

**규칙**
- 공개 대상: 카드 `ready` + 현재 `taxonomy_revision`. Canary 소스 항목 포함(§11). 기본 범위는 `dx`+`dx_dependency`, `excluded`·`irrelevant`는 "전체"를 고를 때만
- 기간 경계는 KST. 레이더 주는 ISO 주(월요일 시작), 분기는 달력 분기. 홈의 1d·7d·30d는 지금부터 거꾸로 센 구간
- 이슈별 1건: 묶음이 있으면 대표 기사, 아직 묶이지 않은 항목은 자기 자신(콘솔 `dedup`과 같은 규칙)
- 키워드 집계: 카드 키워드를 소문자·공백 제거로만 맞춰 센다(정규화 사전 없음). 최소 3건 이상만 순위에 올림
- 집계 단위: 히트맵·점유율은 **항목** 수, KPI의 이슈 수는 묶음 수

**접근 경로:** 웹 서버만 내부망으로 호출한다. Caddy에서 `/api/public/*`도 외부 404, 키는 콘솔 키와 **별도인** `PUBLIC_API_KEY`(§11).

## 6. 캐싱

`cacheComponents`는 켜지 않는다(콘솔의 `force-dynamic` 구성 유지). 공개 API 호출에 `fetch`의 `next.revalidate`·`next.tags`를 쓴다.

| 데이터 | revalidate |
|---|---|
| 홈 items·facets·insights | 300초 |
| 최신 다이제스트 | 600초 |
| 레이더: 진행 중인 기간 / 끝난 기간 | 600초 / 86400초 |
| taxonomy | 3600초 |

## 7. 접근성

패싯은 실제 체크박스, 시트는 Radix Dialog(포커스 가두기·Esc), 히트맵 칸은 `<button aria-pressed>` + 건수·증감을 읽는 `aria-label`, 표 보기 제공, 증감은 ▲▼ 기호와 숫자를 함께, R1 대비 기준, `prefers-reduced-motion` 준수.

## 8. 보안

독자 영역 인증 없음. `/console`·`/api/admin`·`/api/public` 외부 차단 유지·추가. 공개 응답에 본문 전문·운영 정보 없음. 검색어 ILIKE 이스케이프, 페이지 크기 상한 50.
